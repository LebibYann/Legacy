# Formats Overview

This document catalogs on-disk and auxiliary formats used by legacy GeneWeb.

## 1. .gwb Directory Layout

```
<basename>.gwb/
  persons/ families/ ascends/ descends/ unions/ couples/ strings/   (array segment files)
  etc/        (configuration *.gwf, lexicons, particles)
  images/     (person pictures)
  notes/      (public notes pages)
  wiznotes/   (wizard-only notes)
  cnt/        (counters, private keys e.g. gwd_private.txt)
  cache/      (generated gzip caches: *_fnames.cache.gz, etc.)
```
Actual array file naming may differ (legacy uses flat files, sometimes with extensions). The Driver abstracts file names; treat directory as opaque except documented subdirs.

## 2. Core Array Semantics

| Array | Content | Notes |
|-------|---------|-------|
| persons | Person records (name parts, sex, refs to ascends/unions, events indexes) | Fixed index = iper. |
| families | Family records (father iper, mother iper, children list) | ifam index stable. |
| ascends | For each person: reference to family of parents (if any). | - |
| unions | For each person: array of family ids where person is spouse. | Maintains marriage order. |
| descends | For each family: list of children ipers. | Mirrors children in family record. |
| couples | Normalized spouse pairings (for quick lookup / selection). | Derived. |
| strings | Interned strings table (names, places, notes fragments) | Reduces duplication. |

## 3. Person Key Format

`FirstName.occ SURNAME`
- `occ` = occurrence number among persons with identical normalized first names + surname.
- Stored as string used in URLs and exports.

## 4. Cache Files (Autocomplete/Search)

Generated by `cache_files` into `cache/`.

| Filename Suffix | Field | Generation Trigger |
|-----------------|-------|--------------------|
| `_fnames.cache.gz` | Primary first names | After name changes/import. |
| `_surnames.cache.gz` | Primary surnames | Same. |
| `_aliases.cache.gz` | Aliases | When adding alias fields. |
| `_pub_names.cache.gz` | Public/display names | After visibility name edits. |
| `_qualifiers.cache.gz` | Name qualifiers | Rare updates. |
| `_places.cache.gz` | Event & marriage places | After place edits/import. |
| `_titles.cache.gz` | Titles | After title edits. |
| `_estates.cache.gz` | Estate places | Title/estate edits. |
| `_occupations.cache.gz` | Occupations | Occupation field edits. |
| `_sources.cache.gz` | Source strings | Source edits/import. |

All gzip compressed UTF-8, one entry per line, sorted lexicographically (stable diffs).

## 5. NLDB (Notes Links Database)

Built by `update_nldb`.
- Captures mapping page → person links & page links.
- Maintains frequency cache: `notes/cache_linked_pages_name` (serialized hashtable of person key → count).
- Page categories: base notes, wizard notes, misc notes (nested path), person notes (including sub-event notes), family event notes.

## 6. GEDCOM Import Considerations

`ged2gwb` supports character sets: ANSEL, ANSI, ASCII, MSDOS, MAC, UTF-8.
- Converts everything to internal UTF-8.
- Date tags (`DATE`) parsed with qualifiers; unrecognized tags optionally appended to notes when `-untreated_in_notes`.

## 7. Export Formats

| Tool | Format | Notes |
|------|--------|-------|
| `gwb2ged` | GEDCOM 5.x variant | Optional index sections with `-indexes`. |
| `gwu` | GeneWeb textual `.gw` / `gwplus` | `encoding: utf-8` + `gwplus` header (unless `-raw`/`-old_gw`). |
| `gwexport` | Plain text listing | Selection dependent, optionally picture paths. |

## 8. Notes Storage

- Base `notes/` directory: pages / subdirectories form wiki-like hierarchy; path separators replaced by `NotesLinks.char_dir_sep` when indexing.
- `wiznotes/`: restricted pages.
- Individual & family event notes stored in structured fields referencing strings table entries; exported/rendered as needed.

## 9. Lock & Admin Files

- `gwd.lck` (or variant): mutual exclusion.
- `cnt/gwd_private.txt`: secret nonce seed for digest auth; regenerated if absent.
- Other counters (page hits, maybe sequence counters) may appear under `cnt/`.

## 10. UTF-8 & Legacy Encodings

All persisted new text is UTF-8; legacy fix pass (`gwfixbase -invalid-utf8`) scans and rewrites invalid sequences.

## 11. File Naming Stability

Indices (iper, ifam) position within arrays must remain stable across operations unless explicitly re-linked; tools avoid reordering arrays, instead patch in-place or append.

## 12. Derived vs Source Data

| Derived | Source |
|---------|--------|
| Consanguinity coefficients | Imported raw person/family facts |
| Autocomplete caches | Person/family core arrays |
| NLDB link frequencies | Notes text |
| Key occurrences | Names |
| Garbage-collected string table | Historic duplicated strings |

Regeneration order after significant import: `gwfixbase` → `consang` → `cache_files -all` → `update_nldb`.
